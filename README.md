# 🍷 Guia Turístico SR

Aplicativo desenvolvido em Flutter com o objetivo de divulgar a Rota do Vinho e os principais pontos turísticos de São Roque - SP.

O projeto permite que turistas e moradores encontrem vinícolas, restaurantes, hotéis e atrações da cidade por meio de um mapa interativo e recursos de personalização.

* Cristiane Barros

## 📱 Funcionalidades

* Autenticação com Google
* Mapa interativo
* Geolocalização do usuário
* Sistema de favoritos
* Perfil do usuário
* Monitoramento de conectividade
* Tratamento de erros
* Filtro de pontos turísticos por categoria

## 🛠️ Tecnologias Utilizadas

* Flutter
* Dart
* Firebase Authentication
* Google Sign-In
* Flutter Map
* OpenStreetMap
* Connectivity Plus

## 🚀 Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/guiaturisticosr.git
```

2. Acesse a pasta do projeto:

```bash
cd guiaturisticosr
```

3. Instale as dependências:

```bash
flutter pub get
```

4. Execute o projeto:

```bash
flutter run
```
